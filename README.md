# Kilometer Null – GitHub Pages

Dieser Ordner enthält die fertig gebaute statische App.

Alle Dateien aus diesem Ordner in das Hauptverzeichnis des GitHub-Repositories hochladen. Danach unter **Settings → Pages** die Veröffentlichung aus dem Branch `main` und dem Ordner `/ (root)` aktivieren.

Es ist keine Installation und kein Build-Schritt erforderlich.
